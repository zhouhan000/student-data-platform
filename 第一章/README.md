# 学生信息管理系统

## 项目简介

这是一个基于 Python 开发的学生信息管理系统，使用 JSON 实现数据持久化，并采用面向对象的设计方式。系统主要实现学生信息的增删改查、成绩统计、最高分查询、数据备份与恢复以及 CSV 数据导出等功能。

## 主要功能

- 添加学生信息
- 查询学生信息
- 修改学生成绩
- 删除学生信息
- 自动进行成绩等级评价
- 展示所有学生成绩
- 统计成绩数据
- 查看最高分学生
- 备份学生数据
- 恢复备份数据
- 导出 CSV 成绩文件

## 项目结构

- `main.py`：程序主入口和菜单交互
- `storage.py`：数据保存、读取、备份、恢复和导出
- `student_manager.py`：学生信息管理和成绩统计
- `students.json`：学生数据文件
- `students_backup.json`：学生数据备份文件
- `students.csv`：导出的成绩文件

## 使用技术

- Python
- JSON
- CSV
- 面向对象编程
- 异常处理
- 模块化设计
