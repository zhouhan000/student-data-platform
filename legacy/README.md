# 历史命令行代码

这里只保留学习过程中的旧版本；当前只维护根目录 `app/` 中的 FastAPI + SQLite API。

## 归档内容

- `json_cli/`：JSON 命令行入口、学生管理类、文件存储模块和原始 README。
- `sqlite_cli/`：早期 SQLite 命令行入口和管理类。

归档源码的业务逻辑未修改。原始 README 可能已过时，不作为当前项目的启动说明。

## 维护状态

这些目录不是受支持的运行入口，当前 API 与测试都不导入这里的代码。

SQLite 命令行管理类仍依赖早期的按姓名操作接口和三字段查询结果，与当前按 ID 操作的数据库模块不兼容；本次不修复这些历史接口。

JSON 命令行代码中的文件路径相对于源码位置。归档后直接运行可能在归档目录生成新的数据文件，而不是使用 `第一章/` 中的原数据。因此不提供启动命令，也不要用它管理当前数据。

## 数据与共享规则

旧数据库、JSON 和备份文件没有随源码迁移，仍保留在原来的本地位置。

当前 API 使用的成绩等级规则已经提取到 `app/grading.py`，主线不再依赖历史 `storage.py`。历史存储模块中的同名函数只属于归档代码。

如需重新维护命令行版本，应单独设计其依赖和数据路径，并补充测试；不要直接把归档代码重新接入当前 API。
