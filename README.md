# 学生信息管理系统

一个基于 Python 的命令行学生信息管理系统，用于练习模块化设计、文件持久化和异常处理。

## 功能

- 学生信息增删改查
- JSON 数据持久化
- 数据备份与恢复
- 成绩统计
- 最高分查询
- 学生数据导出
- 输入和文件异常处理
## 项目结构

```text
第一章/
├── 学生信息管理.py    # 主程序与菜单
├── student_manager.py # 学生管理类
└── storage.py         # 数据保存、读取、备份和恢复
```

## 运行方式

```bash
python 第一章/学生信息管理.py
```
